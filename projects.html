Projets BTS SIO – option SISR

Deux situations professionnelles réalisées en maquette (VMware) à la CCI Campus Strasbourg, en groupe, avec étude du cahier des charges, budget, planning, schéma réseau, démonstration technique et documentation complète.

AP3 · Projet M2i · 2026 (en cours)

Infrastructure haute disponibilité multi-sites

Fournir à un centre de formation un système d’information redondé et sécurisé, avec une liaison chiffrée entre deux sites (Strasbourg et Mulhouse).

Windows Server 2022/2025 Active Directory GPO DNS / DHCP DFS / DFSR iSCSI / SAN VPN IPsec pfSense VMware ANSSI
  • VPN IPsec site à site entre deux routeurs/pare-feu pfSense
  • Active Directory : 4 contrôleurs de domaine Windows Server (GUI et Core), DNS, DHCP avec basculement
  • DFS / DFSR : espace de noms commun et réplication des données entre les 4 serveurs
  • Sauvegarde complète et clichés instantanés sur SAN via iSCSI
  • GPO et règles de pare-feu selon les recommandations de l’ANSSI

Linux Debian / Ubuntu GLPI Active Directory RGPD ITIL Windows 11 Pro Déploiement d’images VMware

  • Déploiement de logiciels et d’images système sur Windows 11 Pro
